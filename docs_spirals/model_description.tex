\section{General considerations}
This document provides a detailed and technical documentation for our model of spiral arms, implemented as a modification of \verb*|IMFIT| package, available at~\url{https://github.com/IVChugunov/IMFIT_spirals}.

Our model describes 2D surface brightness distribution in spiral arms. Each arm is modelled independently, and model parameters correspond to arms physical properties or connected with them. The number of parameters (17 for a single arm for the most common function) makes the model flexible enough.

The model was constructed according to the results of investigation of spiral arm surface brightness profile in~\href{https://ui.adsabs.harvard.edu/abs/2025Galax..13...44C/abstract}{Chugunov et al. (2025)}. The key properties of the model are also described in Section 4 of this work.

Our model is represented in have 7 different functions, however all of them correspond to our model, and this implementation is done for convenience only (for example, in a function for the most common use, some of the less significant parameters are removed from the set of input parameters and set default inside).

At first, we have a a baseline function \verb*|SpiralArm| producing smooth spiral arms for the general use and describe it primarily. Next, we have two functions which only difference from the baseline that it is able to produce once- and twice-bent arms (\verb*|SpiralArm1b| and \verb*|SpiralArm2b|, respectively). The nuances of bendings are described at Section~\ref{sec:bending}. Moreover, for each these variation we have an extension with additional parameters, allowing fine-tuning of the profile; they are called \verb*|SpiralArmFull|, \verb*|SpiralArmFull1b| and \verb*|SpiralArmFull2b| respectively, described in Section~\ref{sec:fine_tuned}. We also have \verb*|SpiralSpur| function which is the ``reduced'' version of the baseline function designed to fit small elements of spiral structure.

\section{Exact formula for the baseline function}
To describe 2D surface brightness distribution, polar coordinates $I(r, \varphi)$ in the galaxy disc plane are used. Here, $r$ is a galactocentric distance, $\varphi$ is an azimuthal angle counted from some direction. Let the beginning of a spiral arm be located at azimuthal angle $\varphi_0$. For a convenience we'll be use coordinate $\psi$ (winding angle) which is counted from the beginning of a spiral arm towards its winding direction. Thus $\psi = \varphi - \varphi_0$ if spiral arm winds counterclockwise, and $\psi = \varphi_0 - \varphi$ in the opposite case. The final formula consists of a few parts:

\begin{equation}
	I(r, \psi) = I_\parallel(r(\psi), \psi) \times I_\bot(r - r(\psi), \psi)
\end{equation}

Here, $I_\parallel$ is a surface brightness distribution along the ridge-line of the spiral, which is described by the shape function of the arm $r(\psi)$. $I_\bot$ is a surface brightness distribution across the arm. Now let's consider each of the functions separately.

\subsection{Arm shape: $r(\psi)$}
Shape function of the arm $r(\psi)$ describes the overall shape of the spiral arm, more precisely defines its ridge-line. In our implementation, $\log r$ is a 4-th degree polynomial of $\psi$. (In the case of logarithmic spiral, $\log r$ is a linear function of $\psi$).

\begin{equation}
	\label{eq:r_psi}
	r(\psi) = r_0 \times \exp \left(\sum_{n=1}^4 k_n (\psi / \psi_\text{end})^n\right)
\end{equation}

Coefficients $k_n$ are not explicitly used as function parameters, but instead are derived from parameters that are more convenient for use. Parameters include the coordinates of the beginning of the arm $(r_0, \varphi_0)$, and the coordinates of its end $(r_\text{end}, \varphi_\text{end})$. These parameters also define the number of spiral revolutions and the winding direction. For example, if $\varphi_0 = 30^\circ,~\varphi_\text{end} = -510^\circ$, than spiral winds clockwise and makes one and a half revolution. If $\varphi_0 = 90^\circ,~\varphi_\text{end} = 450^\circ$, than spiral winds counterclockwise and makes one revolution.

For $\psi$ coordinate, indices are used in the same way as for $\varphi$, for example $\psi_\text{end}$ is a $\psi$ coordinate where $\varphi = \varphi_\text{end}$.

The function also includes parameters $m_2, m_3, m_4$ which define the deviation of $r(\psi)$ from the logarithmic spiral.

\subsubsection{$k_n$ coefficients}
$k_n$ coefficients are derived from the following:
\begin{equation}
\left\{\begin{array}{l}
	k_1 = m_1 - m_2 + m_3 - m_4 \\
	k_2 = m_2 - 3 m_3 + 6 m_4 \\
	k_3 = 2 m_3 - 10 m_4 \\
	k_4 = 5 m_4
\end{array}\right.\
\end{equation}
where $m_1 = \ln{(r_\text{end} / r_0)}$.

\subsubsection{Motivation of using $m_{2 \ldots 4}$ instead of $k_n$}
There is a number of reasons why $k_n$ coefficients are not used as function parameters, but derived from $m_{2 \ldots 4}$ as above.
\begin{itemize}
	\item At first, when $m_{2 \ldots 4}$ coefficients are used as parameters, spiral arm passes through the points $(r_0, \varphi_0)$ and $(r_\text{end}, \varphi_\text{end})$ regardless of $m_{2 \ldots 4}$ values, and $k_n$ coefficients are not independent from each other.
	\item Parameters $m_{2 \ldots 4}$ are closely tied with the Legendre polynomial expansion coefficients for the pitch angle (Eq.~\ref{eq:mu_psi}). Therefore, each of the coefficients $m_{2 \ldots 4}$ represents the deviation of spiral arm shape from the logarithmic spiral, and coefficients make deviations mostly independent from each other because Legendre polynomials are orthogonal. If we would use $k_n$ as function parameters, it would be some degree of degeneracy between them, because the increase of all $k_n$ coefficients increases the pitch angle of the spiral arm, and for $k_{2 \ldots 4}$ the increase is also stronger for the end of the arm. 
\end{itemize}

The influence of $m_{2 \ldots 4}$ coefficients on the spiral arm shape is shown on Fig.~\ref{fig:Coeffs}.

\subsubsection{Pitch angle}
Spiral arms in our model can have variable pitch angles. Pitch angle $\mu$ at the winding angle $\psi$ is counted as following:

\begin{equation}
	\label{eq:mu_psi}
	\mu(\psi) = \arctan \left(\sum_{n=1}^4 n k_n \psi^{n - 1} / \psi_\text{end}^n\right).
\end{equation}

Average pitch angle $\langle\mu\rangle$ over any $\psi$ range can be found as an arctangent of the slope coefficient of the linear approximation of $\log r(\psi)$.

\subsection{Distribution of the light along the arm: $I_\parallel$}
Function $I_\parallel$ describes the light distribution along the ridge-line of the spiral arm, defined by $r(\psi)$. Because the spiral arm is a part of a disc, it's natural to assume that light distribution is exponential with radius at the most part of the spiral arm. To make the beginning and the ending of arm smooth, this exponential decrease is multiplied by the truncation function of $\psi$. The main part and the modification can be separated and be considered independently:

\begin{equation}
	\label{eq:I_parallel}
	I_\parallel(r, \psi) = I^\text{sp}_0 \times I_{r \parallel}(r) \times T(\psi)
\end{equation}

\begin{equation}
	I_{r \parallel}(r) = e^{-r \times ih_\text{sp}}
\end{equation}

\begin{equation}
	T_{\psi \parallel}(\psi) = s\left(\frac{\psi}{\psi_\text{growth}}\right) \times s\left(\frac{\psi_\text{end} - \psi}{\psi_\text{end} - \psi_\text{cutoff}}\right)
\end{equation}

\begin{equation}
	s(x) =
	\left\{\begin{array}{ll}
		0 & x < 0 \\
		3x^2 - 2x^3 & 0 \leq x < 1\\
		1 & x \geq 1
	\end{array}\right.\
\end{equation}

Above, $I^\text{sp}_0$ is the projected surface brightness from the exponential part at the galaxy centre. Normally, spiral arm does not reach this brightness anywhere because the exponential decrease part of the arm begins from the off galaxy centre, as well as the arm as a whole. Such notation is chosen because it makes $I_{r \parallel}(r)$ have almost the same form as for exponential disc, with $I^\text{sp}_0$ similar to the disc central surface brightness $I_0$. The value $ih_\text{sp} = 1 / h_\text{sp}$ is an inverse exponential scale of the spiral arm $h_\text{sp}$\footnote{Despite exponential scale is widely used for discs description, we do not use it for spirals. Spiral arms sometimes have increasing or constant brightness towards towards higher $r$, and $h_\text{sp}$ in these cases would be negative and/or have very large absolute value. Meanwhile, $h_\text{sp}$ close to zero is usually unreasonable, so using $ih_\text{sp}$ as a parameter ensures that the range of reasonable parameters is continuous and compact.}. Both $I^\text{sp}_0$ and $ih_\text{sp}$ are parameters of the function.

At $\psi_\text{growth}$, $I_{\psi \parallel}(\psi)$ stops increasing and becomes equal to 1, and therefore $I_\parallel(r, \psi)$ becomes purely exponential with radius (if $\psi_\text{cutoff} > \psi_\text{growth}$). At $\psi_\text{cutoff}$, $I_{\psi \parallel}(\psi)$ starts decreasing from 1, and $I_\parallel(r, \psi)$ overall decreases faster than exponentially with radius, reaching zero at the end. Instead of these angles, normalized values of them (as parts of total arm winding angle) are used as function parameters: $p_\text{growth} = \psi_\text{growth} / \psi_\text{end}$ and $p_\text{cutoff} = \psi_\text{cutoff} / \psi_\text{end}$, for the reasons of universality.

\subsection{Distribution of the light across the arm: $I_\bot$}

Distribution of the light across the arm is defined by the function $I_\bot$ which is a simple symmetric Gaussian. We introduce $\rho = r - r(\psi)$ which is a radial distance from the point to the ridge-line of the spiral arm.

\begin{equation}
	\label{eq:I_bot}
	I_\bot(\rho, r) = \exp \left(-\ln(2) \times \left( \frac{\rho}{w_\text{loc}(\psi)} \right)^2 \right)
\end{equation}

Here, local width $w_\text{loc}(r)$ is a HWHM\footnote{HWHM (half-width at half maximum) is a distance from the center to the location where the intensity equals half of peak intensity} of the arm in a radial direction, which dependence of $r$ is the following:

\begin{equation}
	\label{eq:w_loc}
	w_\text{loc}(r) = (w_\text{zp} + w_i r) / 2
\end{equation}

Therefore, $w_\text{zp}$ and $w_i$ are linear coefficients defining width as a function of galactocentric radius.

\section{Additional functions}
\label{sec:add_functions}

\subsection{Varieties of the function with bending}
\label{sec:bending}
We implement functions which have one bending (two smooth parts, \verb*|SpiralArm1b|) and two bends (three smooth parts, \verb*|SpiralArm2b|). At the location(s) of bend(s), pitch angle changes abruptly. Formally speaking, $r(\psi)$ for these functions is defined piecewise. Over each smooth part, $r(\psi)$ is a polynomial function, but the coefficients are independent at each smooth part. For once-bent model, there are 2 polynomials of 3rd degree, and for twice-bent there are 3 polynomials of 2nd degree. The location(s) of one (or two) bends $(r_\text{break}, \varphi_\text{break})$ are also included into the list of function parameters. Obviously, adjacent smooth parts meet at the bending position. This is the only difference between the function varieties.

\subsection{Fine-tuned profiles}
\label{sec:fine_tuned}

As an extension to functions described before, we implement functions with extra parameters which allow one to add fine tuning to brightness distribution of spiral arms: add skewness of the profile, generalise Gaussian profile as S{\'e}rsic and add brightness dips.

These extensions for \verb*|SpiralArm|, \verb*|SpiralArm1b| and \verb*|SpiralArm2b| are called, respectively, \verb*|SpiralArmFull|, \verb*|SpiralArmFull1b| and \verb*|SpiralArmFull2b|. Now the properties of these extensions will be presented as a difference from original functions.

First, we describe the changes to $I_\bot$ (Equation~\ref{eq:I_bot}):

\begin{equation}
	I_\bot^\text{in/out}(\rho, \psi) = \exp \left(-\ln(2) \times \left( \frac{|\rho|}{w_\text{loc}^\text{in/out}(r)} \right)^{\frac{1}{n}} \right)
\end{equation}

This function now takes the form of asymmetric S{\'e}rsic profile with an additional parameter $n$ which defines the shape of the profile. It still has Gaussian as a specific case if $n = 0.5$. One can note that, instead of $b_n$ depending on $n$, the constant $\ln(2)$ stays in the exponent. This leads to $w_\text{loc}^\text{in/out}(\psi)$ being not an effective radius containing a half of spiral arm luminosity\footnote{Actually, if $b_n$ is taken from a traditional form of S{\'e}rsic function, the value that is considered to be an effective radius in common 2D S{\'e}rsic profile will encircle much more than a half of light, depending on $n$. For typical $n$ of spiral arms in the range of $0.5 \ldots 1$, this fraction equals nearly 80\%.} but a HWHM (just as for the baseline function). It is more convenient to use such definition in practice.

Indices $^\text{in}$ and $^\text{out}$ denote, respectively, inner part of the arm relative to ridge-line of the arm ($\rho < 0$), and outer ($\rho > 0$), because inner and outer half-widths $w_\text{loc}^\text{in}$ and $w_\text{loc}^\text{out}$ are also different. Equation~\ref{eq:w_loc} takes the following form:

\begin{equation}
	w^\text{in/out}_\text{loc}(r) = (w_\text{zp} + w_i r) \frac{1 \mp S_\text{loc}(r)}{2}
\end{equation}

where $\mp$ means ``$-$'' for inner and ``$+$'' for outer. The local skewness $S_\text{loc}(r)$ is defined as following:

\begin{equation}
	S_\text{loc}(r) = S_{zp} + S_i r
\end{equation}

Instead of $S_{zp}$ and $S_i$, function parameters $S_0$ and $S_\text{end}$ are used, which define $S_\text{loc}(r_0)$ and $S_\text{loc}(r_\text{end})$ respectively.

Also, there is an extension to $I_\parallel$ (Eq.~\ref{eq:I_parallel}):

\begin{equation}
	I_\parallel(r, \psi) = I^\text{sp}_0 \times I_{r \parallel}(r) \times T(\psi) \times D(\psi)
\end{equation}

where $D(\psi)$ is a function describing surface brightness dips in spiral arms based on Gaussian functions:

\begin{equation}
	\begin{array}{ll}
		D(\psi) = 1 / [1 + \sum_i G(A_i, \psi_i^c, \psi_i^w)]\\
		G(a, b, c) = a \exp\left[-\frac{(x - b)^2}{2c^2}\right]
	\end{array}
\end{equation}

Therefore, for each dip $A_i, \psi_i^c, \psi_i^w$ are brightness dip depth, its location and width respectively. Our function supports up to 2 dips in a single arm, so we have additional parameters $A_1, \psi_1^c, \psi_1^w, A_2, \psi_2^c, \psi_2^w$.

\subsection{Spurs}
\label{sec:spurs}
Finally, the function \verb*|SpiralSpur| is essentially a reduced \verb*|SpiralArm|. It has smaller number of parameters: $m_3$, $m_4$, $ih_\text{sp}$ and $w_\text{zp}$ are removed and the function is the same to \verb*|SpiralArm| with all these parameters are set zero. This simplified function is designed to fit smallest spiral features.
